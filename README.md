# Final Capstone Portfolio

This repository brings together production web-engineering case studies and
the data-science coursework that started the original capstone:

- [EverythingIT.ie WordPress Transformation](everythingit-wordpress-transformation/README.md) — production WordPress/Elementor engineering, technical SEO, information architecture, automation, accessibility and release verification.
- [AZWebCorp SEO and Platform Engineering](seo-audit/) — custom WordPress tooling, automated site audits, lead follow-up workflows, schema, security pages, redirects, cache control and production verification.
- [Palo Verde Cancer Specialists](paloverde-cancer/) — responsive Elementor content remediation, location-page engineering and reusable WordPress presentation components.
- [Prestige Windows](prestige-windows/README.md) — frontend refinement, live-site auditing, deployment utilities, navigation/footer work and technical search improvements.
- Data science coursework — notebooks and datasets retained from the original capstone repository.

The portfolio documents real production work while deliberately excluding
credentials, private backups, customer data and hosting configuration secrets.

## Engineering themes

- Production WordPress and Elementor development
- PHP, Python, PowerShell, HTML, CSS and JavaScript automation
- Technical SEO, structured data, canonicalization and redirect engineering
- Safe deployment with scoped backups, cache invalidation and public verification
- Accessibility, responsive behavior and reusable design components
- CDN, managed-host and application-cache diagnosis

Each project directory contains the safest useful subset of its implementation,
documentation and verification evidence. Live sites can evolve independently of
the snapshots stored here.
