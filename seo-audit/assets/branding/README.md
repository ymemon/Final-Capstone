# AZWebCorp Brand Assets

Production logo variants used by azwebcorp.com.

- `Azwebcorp-black_logo.png` — dark wordmark for light header contexts.
- `Azwebcorp-white_logo.png` — reversed wordmark for dark footer contexts.

## 2026-08-24 revision

- Replaced the lime-yellow `Z` with the site's warm orange-coral accent.
- Refined the cactus-shaped `W` to be thinner and easier to read.
- Preserved transparent PNG output at the production dimensions, 452 × 146.

The prior production files were backed up on the managed WordPress host before
deployment. Credentials, server backups, and hosting-specific secrets are not
stored in this repository.
