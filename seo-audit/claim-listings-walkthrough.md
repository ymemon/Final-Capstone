## 1. Google Business Profile
**Why first:** highest-value listing by far — feeds Google Maps, local pack rankings, and the knowledge panel.

1. Go to **business.google.com**
2. Sign in with whichever Google account should own this (ideally a real AZWebCorp account, not a personal one, for long-term access continuity)
3. Search "AZWebCorp" — if a profile already exists but unclaimed, click **Claim this business**. If none exists, click **Add your business**.
4. Enter the NAP data from the table above exactly as written
5. Choose verification method — usually **postcard by mail** (5–7 days to the physical address above) or **phone/text** if offered
6. Once verified, add: logo, a few real photos of the office/team if available, and the same short description

## 2. Bing Places for Business
1. Go to **bingplaces.com**
2. Sign in with a Microsoft account (or create one — doesn't need to be tied to anything else)
3. **Tip:** Bing Places can often **import directly from your Google Business Profile** once that one's verified — do Google first, then use the import option here to save re-entering everything
4. If entering manually, use the same NAP data above
5. Verification is usually instant or via phone call

## 3. Yelp for Business
1. Go to **biz.yelp.com**
2. Search "AZWebCorp" in Gilbert, AZ first — Yelp often has an unclaimed listing already generated from public data
3. If found: click **Claim this business** → verify via phone call/text to the business number
4. If not found: **Add your business** → enter the same NAP data
5. Fill out the profile: category "Web Design", add the short description, add the website URL
